# Registry Wiki

Registry is Chromatic's native Windows registry editor and command-line companion. It supports familiar local-registry workflows while adding explicit architecture selection, previewed `.reg` imports, export-first safety, and a Journal for changes made by the app.

## Start here

- [Installation](Installation.md) — choose x64 or ARM64, verify an unsigned release, and use the command aliases.
- [Safe editing](Safe-editing.md) — a careful workflow for keys, views, backups, and protected paths.
- [Importing .reg files](Importing-reg-files.md) — preview operations before applying them.
- [Journal and recovery](Journal-and-recovery.md) — understand snapshots and their limits.
- [CLI reference](CLI.md) — commands for scripts and diagnostics.
- [Architecture](Architecture.md) — desktop app, shared core, and release layout.
- [Known limitations](Known-limitations.md) — current product boundaries.

Registry is developed and published by [Chromatic](https://chromatic.hu). Send product feedback to [feedback@chromatic.hu](mailto:feedback@chromatic.hu). Security reports belong in [private GitHub security advisories](https://github.com/Has-X/Registry/security/advisories/new), not public issues.
